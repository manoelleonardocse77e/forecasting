#Descrição
<p>Este é um projeto busca dados de criptmoedas através do banco de dados do Yahoo Finance, cria um dataframe com as informações e através da regressão linear (utilizando o valor de fechamento e a data) faz uma estimativa de valores futuros baseado na demanda do usuário</p>

#Como utilizar:
<p>Após devidamente importar todas as bibliotecas e rodar o código, digite o comando streamlit run "nome_do_arquivo".py no console. Após a dashboard abrir, selecione a criptomoeda e quantos dias no futuro o algoritmo deverá utilizar em sua estimativa. Os gráficos devem indicar seus resultados</p>
<p>Se seu Python não estiver globalmente instalado, adicione python -m ao streamlit run.</p>
